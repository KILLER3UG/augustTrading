v3 — sparser, on purpose

v2 was a restyle of the same dense layout. v3 removes content instead. The reference screens (Kimi new-chat, Claude home) share one trait above all: most of the screen is empty on purpose — one greeting, one composer, nothing else until the trader asks. That can't literally hold for a chart surface (the chart is the product), so v3 keeps the chart full-bleed and makes everything around it quieter than the reference: fewer rows, fewer labels, nothing competing with the tape.

What stays August

Geist, not serif (charter). Monospace tabular numerals. One cyan = entry. Basis-rate math and the funding refusal survive every pass unchanged — minimalism never costs the trader the number that says how sure. No serif, no coral/blue brand color, no upsell rows, no marketing. Signal lifecycle (expiry, ledger resolution, bot-identity claim) still on the card.

Implementation mapping (same as v1/v2)

Shared SignalCard for TradeChatPanel + AgentsView; emit receipt links SignalRecord.id / expiresAt; verdict overlay (verdictLevels) vs card lines (onChatLevels + ownerId) stay distinct; OrderBookPanel as collapsible chart drawer (Analyze-only portal, single-column GRID); SignalFeed scorecard up from Journal; BiasChips into Agents with honest failure state. Gates: typecheck, lint, build, render-probe, manual 1440/800 look. Header metrics become the chart crosshair readout (TradeView tape stays as the source — it is not deleted, it is not a visible band).
