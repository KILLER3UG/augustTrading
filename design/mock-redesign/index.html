Design principles applied

  • Signal is the hero. Direction, trigger, invalidation, targets, timeframe, confidence and evidence — the focus doc's checklist — sit above the prose on both surfaces. Prose explains; the headline decides.
  • Accuracy is shown, not asserted. Probability always pairs with its base rate and n; a thin sample gets an amber note, not a footnote. Refusals (funding too thin) are first-class evidence rows.
  • One cyan, one meaning. Cyan = entry/trigger only (line, label, kv value). Emerald/rose stay data hues; chrome stays zinc.
  • Whitespace over boxes. Reference discipline: separation by space and type; borders only for data tables, the composer, and the attach card.
  • Prose vs chrome. The answer reads at font-reading scale; disclosures and the composer stay interface chrome. No layout shift on stream.
  • Never implies execution. Every action reads Log plan / Pin / Copy / Show. The disclaimer stays quiet and permanent.
  • Deliberately not borrowed: the serif greeting headline (charter says Geist), coral/blue brand accents (one cyan rule), and upsell rows (voice doc: no marketing).

800px behaviour (toggle above)

  • List column becomes a drawer; the icon rail stays put. Chart never squeezes to a sliver.
  • Dock flattens to a Chart | AI | Book switcher — the existing TradeView three-mode pattern, kept and emphasised.
  • Book drawer goes full-width under the chart; metrics strip collapses to Mark + Funding.
  • Chat column stays 720px-max centred; the signal kv grid wraps to two columns.

Deliberately unchanged

  • Surface ids trade / journal / agents / learn; labels Analyze · Journal · Agents · Learning.
  • One thread across homes: dock and Chat render the same conversation id; claimed by Message.botId.
  • Dock geometry contract (300–820px, persisted, collapsible rail) and the 240px list column.
  • No new hue, no gradient, no new radius, no serif, no text-[Npx].

Signal card → extract from ChatTranscriptRow's verdict + SignalFeed ledger fields into one shared SignalCard mounted by both TradeChatPanel and AgentsView (one home per concern; the emit receipt stops being an anonymous tool row and links SignalRecord.id, its expiresAt countdown and conviction).
